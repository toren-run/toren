# WhatsApp <Badge type="warning" text="coming soon" />

Same model as [Telegram](/channels/telegram): a DM is a durable session, deny-by-default access, one poller elected per deployment, exactly-once turn delivery through the database. WhatsApp's Business API requires app review and a verified business, which makes setup heavier than Telegram's, so Telegram shipped first.

If you want this soon, say so in the repo (it opens with the public launch): things move up the list when people ask.
